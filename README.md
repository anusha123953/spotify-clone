# 🎧 Spotify Clone UI

A Spotify-inspired music streaming interface built using HTML and CSS as part of my frontend development learning journey.

## ✨ Features

- 🎵 Spotify-inspired dark theme
- 📚 Sidebar navigation with Home, Search, and Your Library
- 🖼️ Music cards with album artwork
- 💚 Green play buttons and hover effects
- 🎮 Bottom music playback bar UI
- 📱 Responsive layout

## 🛠️ Tech Stack

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/anusha123953/spotify-clone.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
